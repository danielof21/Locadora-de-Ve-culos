1. Problema & Modelagem Adotada (TP1)

Problema Resolvido: Locadoras de veículos enfrentam inconsistências operacionais ao controlar manualmente a disponibilidade de frota, quilometragem, vínculo entre fabricantes/categorias e histórico de contratos de locação por cliente.

Solução e Arquitetura: Modelagem relacional normalizada implementada com ASP.NET Core Web API / Entity Framework Core e persistência transacional, garantindo integridade referencial (DeleteBehavior.Restrict), índices únicos (CPF, E-mail, Nome de Fabricante/Categoria e Código de Produto) e Check Constraints de domínio.

Entidade Chaves & Restrições Rota Base da API

Fabricantes PK Id | UK Nome (1:N Veículos) /api/fabricantes

Consultas Avançadas, Filtros & Visualizações (Rotas da 3ª Etapa)

Painel conectado ao FiltrosController executando consultas relacionais com INNER JOIN, LEFT JOIN e agregações GROUP BY no banco de dados.

Consulta 1: Veículos Disponíveis (Multi-Filtro)
GET /api/filtros/veiculos-disponiveis

Cruza Veículos, Categorias e Fabricantes (INNER JOIN) e verifica a ausência de locação em aberto (LEFT JOIN Alugueis WHERE DataDevolucao IS NULL).

SELECT v.Id, v.Modelo, v.AnoFabricacao, v.QuilometragemAtual, f.Nome, c.Nome
FROM Veiculos v
INNER JOIN Categorias c ON v.CategoriaId = c.Id
INNER JOIN Fabricantes f ON v.FabricanteId = f.Id
LEFT JOIN Alugueis a ON v.Id = a.VeiculoId AND a.DataDevolucao IS NULL
WHERE a.Id IS NULL AND (@categoriaId IS NULL OR v.CategoriaId = @categoriaId) AND (@anoMin IS NULL OR v.AnoFabricacao >= @anoMin)
ID Modelo Fabricante Categoria Ano KM
Consulta 2: Aluguéis por Cliente (INNER JOIN)
GET /api/filtros/alugueis-por-cliente

Realiza a junção interna entre as tabelas Alugueis, Clientes e Veiculos filtrando dinamicamente pelo nome do cliente.

SELECT a.Id, a.DataInicio, a.DataPrevistaFim, a.DataDevolucao, a.ValorDiaria, c.Nome, v.Modelo
FROM Alugueis a
INNER JOIN Clientes c ON a.ClienteId = c.Id
INNER JOIN Veiculos v ON a.VeiculoId = v.Id
WHERE LOWER(c.Nome) LIKE '%' + @clienteNome + '%'
ID Cliente Veículo Início Status Diária
